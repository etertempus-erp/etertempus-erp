# Vision del Producto

## Nombre

Eter ERP

## Proposito

Eter ERP existe para que un emprendimiento artesanal pueda administrar compras, formulas, produccion, inventario, ventas y decisiones de negocio sin depender de planillas dispersas.

La primera implementacion esta orientada a Eter Tempus, pero el diseno debe poder crecer hacia otros pequenos productores artesanales.

## Principios

1. Un dato se registra una sola vez.
2. Todo lo calculable se calcula.
3. El sistema registra hechos, no resultados manuales.
4. Nada sale del inventario sin un destino registrado.
5. El ERP registra decisiones, no hace suposiciones.
6. Toda formula conserva historial mediante versiones.
7. El lote nace cuando se elabora la mezcla.
8. El sistema debe explicar sus calculos.

## Version 0.1

La version 0.1 se concentra en el corazon operativo:

- Recursos.
- Formulas.
- Produccion.
- Movimientos de inventario.

Quedan fuera de v0.1:

- IA.
- CRM avanzado.
- Contabilidad completa.
- Facturacion electronica.
- Multiempresa.
- Permisos complejos.
- Dashboard avanzado.
